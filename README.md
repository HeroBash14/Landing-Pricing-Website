# ⚡ Landing Pricing Website

Modern and high-converting Pricing Page designed for **SaaSify**, a premium cloud suite SaaS product. 

This template is meticulously crafted following world-class interactive design standards, delivering an ultra-modern aesthetic with fully functioning client-side logic.

## 🚀 Key Features

1. **Dynamic Billing Toggle (Monthly / Annual)**: Instantly switches pricing plans with high-fidelity transitions and updates all subscription tiers (Starter, Pro, and Enterprise) reflecting 20% annual discount.
2. **Elastic Team Calculator (Dynamic Slider)**: An interactive slider allowing prospective users to estimate custom licensing seats (from 5 to 200) with automatic economies of scale discounts.
3. **High-Converting Product Cards**: Strategically designed product tier cards with visual badges, focus styles on the most popular plan, and clear distinct value propositions.
4. **Detailed Feature Comparison Table**: A comprehensive, fully responsive matrix comparison detailing differences in storage, support SLA, domains, and security parameters across different plans.
5. **Interactive Accordion FAQ**: A cleanly animated FAQ section to preemptively resolve standard pre-purchase hesitations.
6. **Bottom Conversion Hero (CTA)**: A contrastive dark conversion hero at the bottom to maximize free trial user acquisition and lower bounce rate.

## 🛠️ Stack and Technologies Used

- **HTML5 & CSS3** with mobile-first and fluid system fonts.
- **Tailwind CSS (via CDN)** for design system compliance, rapid visual styles, dark mode styling touches.
- **Alpine.js (via CDN)** for lightweight, fast, and reactive client-side interactivity (toggles, sliders, states).
- **Lucide Icons** for modern, crisp vector icons throughout the interface.

## 📦 Getting Started

To launch and run this landing page locally:

1. Clone or download this repository.
2. Direct-open `index.html` on any web browser:
   ```bash
   # Or run with a quick server (e.g. VS Code Live Server or python http.server)
   python3 -m http.server 8000
   ```
3. Open your browser and navigate to `http://localhost:8000`.

## 🎨 Design Philosophy

This mockup implements clean visual typography hierarchy using the Inter font family, utilizing smooth slate backgrounds and rich indigo gradients to focus emphasis on the Professional tier. Designed for maximal trust-building and delightful user interactions.
